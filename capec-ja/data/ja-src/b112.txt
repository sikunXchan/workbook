## 561
name: 盗んだ認証情報によるWindows管理共有の利用
description/0: 攻撃者は、ローカルマシン、あるいはWindowsドメイン内のWindows管理共有にアクセスするため、正当なWindows管理者の認証情報（利用者ID／パスワードなど）を推測、あるいは入手（盗む、あるいは購入する）する。
extended_description/0: Windows NTファミリーに属するWindowsシステムには、システム管理者のみがアクセスできる、隠されたネットワーク共有が含まれている。これらの共有により、管理者は、ネットワークに接続されたシステム上のすべてのディスクボリュームに遠隔でアクセスでき、さらに、ファイルのコピー、書き込み、実行、その他の管理上の操作を行えるようになる。ネットワーク共有の例には、C$、ADMIN$、IPC$が含まれる。攻撃者が正当なWindowsの認証情報を入手できれば、これらの隠された共有に、SMB（サーバーメッセージブロック）やNetユーティリティを介して遠隔からアクセスし、ファイルを転送し、コードを実行できる。また、攻撃者が、特定の設定とパッチレベルを持つシステム上で、管理者共有にアクセスするためにNTLMハッシュを利用することも可能である。
execution_flow/0/description/0: ［既知のWindows管理者認証情報の取得］攻撃者は、管理用のネットワーク共有にアクセスするため、既知のWindows管理者認証情報を入手しなければならない。
execution_flow/0/techniques/0/0: 攻撃者は、ダークウェブから、侵害されたWindows管理者の認証情報を購入する。
execution_flow/0/techniques/1/0: 攻撃者は、キーロガーやフィッシング攻撃を利用して、提供される管理者の認証情報を盗む。
execution_flow/0/techniques/2/0: 攻撃者は、送信中のWindows管理者の認証情報を盗むため、スニッフィング攻撃を行う。
execution_flow/0/techniques/3/0: 攻撃者は、Windowsドメインのシステム／ファイルへのアクセスを獲得し、Windows管理者のパスワードハッシュを持ち出す。
execution_flow/0/techniques/4/0: 攻撃者は、ハードコードされたWindows管理者の認証情報を発見するため、外部に公開されている設定ファイルやプロパティファイルを調べる。
execution_flow/1/description/0: ［ドメイン認証の試行］標的がアクセスを許可するまで、隠されたネットワーク共有に対して各Windows管理者の認証情報を試す。
execution_flow/1/techniques/0/0: 標的のインターフェースを通じて、手動あるいは自動で、各管理者の認証情報を入力する。
execution_flow/2/description/0: ［マルウェアの実行］攻撃者は、ドメイン内の他のシステムに感染させるため、管理用のネットワーク共有内で遠隔からマルウェアを実行できる。
execution_flow/3/description/0: ［データの持ち出し］攻撃者は、管理用のネットワーク共有内に含まれる機微なデータを、遠隔から獲得できる。
prerequisites/0/0: システム／アプリケーションが、Windowsドメインに接続されていること。
prerequisites/1/0: 標的の管理共有が、ドメインシステムへのログインのために、ローカル管理者の認証情報の遠隔使用を許可していること。
prerequisites/2/0: 攻撃者が、標的のドメインに存在する既知のWindows管理者認証情報のリストを持っていること。
skills/0/text/0: 攻撃者が既知のWindowsの認証情報を入手してしまえば、それを利用することは容易である。
resources/0/0: 標的とするドメインの、既知のWindows管理者認証情報のリスト。
indicators/0/0: 管理用のネットワーク共有から、データが転送、および／または削除されている。
indicators/1/0: 管理用のネットワーク共有内で、疑わしい、あるいは悪意あるソフトウェアが実行されている。
examples/0/0: APT32は、Windows組み込みのNetユーティリティを利用して、Windows管理共有を使い、遠隔のマルウェアをコピー・実行していた。［REF-579］
examples/1/0: 2017年5月、APT15は、Windows管理共有を介して、Windowsドメイン内で横方向に移動し、侵害したホストシステムとの間でファイルをコピーした。これによりさらに、マルウェアの遠隔実行が可能になった。［REF-578］
s.summary: 既知のドメイン認証情報の使用（CAPEC-560）の、Windows管理共有に特化した変種。管理者のみがアクセスできる隠しネットワーク共有（C$、ADMIN$など）の認証情報を盗み、ドメイン内の他のマシンへファイルをコピー・実行することで、横方向に移動していく。実例として、APT32やAPT15によるこの手法の悪用が挙げられている。
s.term: Windows管理共有, Windows Admin Shares, Windowsのシステム管理者のみがアクセスできる、隠されたネットワーク共有（C$、ADMIN$、IPC$など）のこと。
s.fact: APT32は、Windows組み込みのNetユーティリティを利用して、Windows管理共有を使い、遠隔のマルウェアをコピー・実行していた、と原典の具体例に書かれている。, CAPEC-561 examples（具体例）
s.analogy: ビルの管理人だけが使える「全室共通の鍵」を盗み出し、各部屋に自由に出入りして、荷物を置いたり持ち出したりしてしまうのに似ている。

## 562
name: 共有ファイルの改変
description/0: 攻撃者は、正当なコンテンツに悪意あるプログラム、スクリプト、あるいはエクスプロイトコードを追加することで、共有場所にあるファイルを操作する。利用者がその共有コンテンツを開くと、汚染されたコンテンツが実行される。
mitigations/0/0: 共有コンテンツを許可しない。書き込みアクセスを持つ利用者を最小限にすることで、共有フォルダを保護する。エクスプロイトの実行を防ぐため、Microsoft Enhanced Mitigation Experience Toolkit（EMET）のような、悪用を緩和するユーティリティを使用する。
s.summary: みんなが見る共有フォルダ内の、普段から使われている正当なファイルそのものに、悪意あるコードを混ぜ込んでおく攻撃。利用者は、いつも使っている共有ファイルを普通に開くだけで、知らないうちに汚染されたコンテンツを実行してしまう。
s.term: 共有フォルダ, shared folder, 複数の利用者がネットワークを通じてアクセスできる、共有されたファイル保存領域のこと。
s.fact: 利用者がその共有コンテンツを開くと、汚染されたコンテンツが実行される、と原典に書かれている。, CAPEC-562 説明
s.analogy: 社内の共用の掲示板に貼られた、いつも見ているお知らせの紙そのものに、こっそり仕掛けを施しておくのに似ている。利用者は普段通りにお知らせを読むだけで、仕掛けに引っかかってしまう。

## 563
name: 共有Webルートへの悪意あるファイルの追加
description/0: 攻撃者は、開かれたファイル共有を通じて、Webサイトに悪意あるコンテンツを追加し、その後、Webブラウザでそのコンテンツを閲覧することで、サーバーにそのコンテンツを実行させることがある。その悪意あるコンテンツは、通常、Webサーバープロセスのコンテキストと権限の下で実行され、Webサーバーがどのように設定されているかによって、しばしばローカルシステムや管理者の権限がもたらされる。
mitigations/0/0: Webサーバーを通じてアクセスできるディレクトリに、適切な権限が設定されていることを確認する。Webルートへの遠隔アクセスを許可しない。Webルート内のディレクトリでの実行を無効化する。組み込みのアカウントを使用せず、代わりに特定のアカウントを作成することで、複数のシステムにわたる不要なアクセスや権限の重複を制限し、Webサーバープロセスの権限が必要最小限のものだけであることを確認する。
s.summary: Webサイトのファイルを管理する共有領域（Webルート）への書き込みアクセスを悪用し、悪意あるファイルを直接追加してしまう攻撃。追加されたファイルは、ブラウザからアクセスされるだけでWebサーバー権限で実行され、Webサーバーの設定によっては、そのままシステムやローカル管理者レベルの権限を得てしまうこともある。
s.term: Webルート, web root, Webサーバーが公開するファイルの、最上位に位置するディレクトリのこと。
s.fact: その悪意あるコンテンツは、通常、Webサーバープロセスのコンテキストと権限の下で実行され、設定によってはローカルシステムや管理者の権限がもたらされる、と原典に書かれている。, CAPEC-563 説明
s.analogy: 店舗の商品陳列スペース（Webルート）に、誰でも自由に商品を置ける仕組みを悪用し、そこに不正な商品をこっそり並べておくのに似ている。客（ブラウザ）がそれを手に取るだけで、店の権限で何かが実行されてしまう。

## 564
name: ログオン時のソフトウェア実行
description/0: オペレーティングシステムは、特定の利用者がシステムにログオンするたびに、ログオンスクリプトを実行できるようにしている。攻撃者がこれらのスクリプトにアクセスできる場合、ログオンスクリプトに追加のコードを挿入することがある。このコードは、対象の利用者がコンピュータにログオンするたびに実行されるため、攻撃者が永続性を維持する、あるいはエンクレーブ内を横方向に移動することを可能にし得る。ログオンスクリプトを改変することで、ワークステーションやエンクレーブのファイアウォールを事実上回避できる。ログオンスクリプトのアクセス設定によっては、ローカルの認証情報、あるいは遠隔の管理者アカウントが必要になることがある。
mitigations/0/0: ログオンスクリプトへの書き込みアクセスを、必要な管理者のみに制限する。
s.summary: 利用者がログオンするたびに自動実行される「ログオンスクリプト」に悪意あるコードを追加しておく攻撃。利用者がログオンするだけで実行されるため、永続的なアクセスの維持や、ネットワーク内の横方向への移動の足がかりとして使われる。ファイアウォールの監視をすり抜けやすい点も厄介である。
s.term: エンクレーブ, enclave, 特定のセキュリティポリシーで保護された、ネットワークの一区画のこと。
s.fact: ログオンスクリプトを改変することで、ワークステーションやエンクレーブのファイアウォールを事実上回避できる、と原典に書かれている。, CAPEC-564 説明
s.analogy: 社員が出社のたびに必ず通る朝礼（ログオンスクリプト）の内容に、こっそり不要な指示を混ぜ込んでおくのに似ている。社員は毎日の習慣として朝礼に参加するだけで、その指示に従ってしまう。
