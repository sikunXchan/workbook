## 555
name: 盗んだ認証情報によるリモートサービスの利用
description/0: この攻撃パターンは、攻撃者が盗んだ認証情報を使って、RDP、telnet、SSH、VNCのようなリモートサービスを利用し、システムにログインすることを伴う。一度アクセスが得られると、様々な悪意ある活動が実行され得る。
mitigations/0/0: RDP、telnet、SSHを無効化し、そのような通信を遮断するファイアウォールルールを有効化する。遠隔での対話的ログインアクセスを持つ利用者とアカウントを制限する。RDPを通じてログインを許可されたグループのリストから、ローカル管理者グループを除外する。遠隔利用者の権限を制限する。遠隔ログインには、リモートデスクトップゲートウェイと多要素認証を使用する。
examples/0/0: リモートデスクトップは、オペレーティングシステムの一般的な機能である。これにより、利用者は、遠隔のシステム上で、システムデスクトップのグラフィカルユーザーインターフェースを使った対話的なセッションにログインできる。Microsoftは、自社のリモートデスクトッププロトコル（RDP）の実装を、リモートデスクトップサービス（RDS）と呼んでいる。RDSと同様に、グラフィカルなアクセスを提供するリモートサービスには、他にも様々な実装やサードパーティのツールが存在する。攻撃者は、そのサービスが有効になっており、既知の認証情報を持つアカウントへのアクセスを許可している場合、RDP／RDS経由で遠隔システムに接続し、アクセスを拡大することがある。
examples/1/0: Windowsリモート管理（WinRM）は、利用者が遠隔システムとやり取りできる（実行可能ファイルの実行、レジストリの変更、サービスの変更など）、Windowsのサービスとプロトコルの両方の名称である。これは、winrmコマンドや、PowerShellのような数多くのプログラムを通じて呼び出すことができる。
s.summary: フィッシングなどで盗んだ正規の認証情報を使い、RDPやSSHのような、管理者が業務で使う正規のリモートアクセス機能そのものを使ってログインしてしまう攻撃。侵入経路として脆弱性を突くのではなく、「正規のログイン」として扱われてしまうため、検知が難しい。
s.term: RDP, Remote Desktop Protocol, Windowsのリモートデスクトップ機能で使われる、遠隔操作のための通信プロトコルのこと。
s.fact: 攻撃者は、既知の認証情報を持つアカウントへのアクセスを許可している場合、RDP／RDS経由で遠隔システムに接続し、アクセスを拡大することがある、と原典の具体例に書かれている。, CAPEC-555 examples（具体例）
s.analogy: 盗んだ社員証を使って、正面玄関の正規の入館ゲートを堂々と通過してしまうのに似ている。入館ゲート自体は正しく機能しているため、警備員には何の異常も見えない。

## 556
name: ファイル拡張子ハンドラの差し替え
description/0: ファイルが開かれる際、そのファイルを開くプログラムを決定するため、ファイルハンドラが確認される。ファイルハンドラは、多くのオペレーティングシステムの設定上のプロパティである。アプリケーションは、特定のファイル拡張子に対するファイルハンドラを改変し、その拡張子を持つファイルが開かれた際に、任意のプログラムを呼び出させることができる。
mitigations/0/0: レジストリの変更を検査する。デフォルトのファイルハンドラへの変更が、認可された管理者によってのみ行えるよう、利用者アカウントの権限を制限する。
s.summary: 「この拡張子のファイルはこのプログラムで開く」という、OSが管理する対応関係（ファイルハンドラ）そのものを書き換えてしまう攻撃。これにより、利用者が通常のファイルを開くつもりでクリックするだけで、実際には攻撃者が指定した任意のプログラムが起動してしまう。
s.term: ファイルハンドラ, file handler, ある拡張子を持つファイルを開く際に、どのプログラムを使うかを定めた、OSの設定情報のこと。
s.fact: アプリケーションは、特定のファイル拡張子に対するファイルハンドラを改変し、その拡張子を持つファイルが開かれた際に、任意のプログラムを呼び出させることができる、と原典に書かれている。, CAPEC-556 説明
s.analogy: 「この種類の荷物が届いたら、必ずこの係に渡す」という社内のルールそのものを、知らないうちに別の係（攻撃者が指定した人物）に差し替えてしまうのに似ている。荷物の送り主や受取人は、ルールが変わったことに気付かない。

## 558
name: 信頼された実行可能ファイルの差し替え
description/0: 攻撃者は、権限管理やアクセス制御の弱点を悪用し、信頼された実行可能ファイルを悪意あるバージョンに差し替え、その信頼された実行可能ファイルが呼び出された際に、マルウェアの実行を可能にする。
Q examples/0/0: Windowsの特定のバージョンには、利用者がログインする前（例えばWindowsのログオン画面にいる間）に、特定のキーの組み合わせで起動できるアクセシビリティ機能が含まれている。Windows XPやWindows Server 2003／R2では、そのプログラム（例えば「C:\Windows\System32\utilman.exe」）が、cmd.exe（あるいはバックドアアクセスを提供する他のプログラム）に差し替えられることがある。その後、キーボードの前に座っている間、あるいはRDP経由で接続している間に、ログイン画面で適切なキーの組み合わせを押すと、差し替えられたファイルがSYSTEM権限で実行されてしまう。
s.summary: OSが標準で信頼して実行する実行可能ファイル（アクセシビリティ機能のプログラムなど）そのものを、悪意あるプログラムに差し替えてしまう攻撃。実例として、ログイン前の画面からでも起動できるアクセシビリティ機能のプログラムをcmd.exeに差し替え、ログイン画面上でそのキー操作をするだけでSYSTEM権限のコマンドシェルを得てしまう、Windowsの古いバージョンに存在した有名な手口が挙げられている。
s.term: SYSTEM権限, SYSTEM privilege, Windowsにおいて、管理者よりもさらに高い、OS自体が持つ最高レベルの権限のこと。
s.fact: このキー操作により、差し替えられたファイルがSYSTEM権限で実行されてしまう、と原典の具体例に書かれている。, CAPEC-558 examples（具体例）
s.analogy: 受付の呼び出しボタン（アクセシビリティ機能）の裏側の配線を、警備員を呼ぶものから、金庫室の鍵を自動で開ける仕組みにこっそりつなぎ替えてしまうのに似ている。来客は普通にボタンを押すだけで、金庫室が開いてしまう。

## 559
name: 軌道上での妨害電波攻撃
description/0: この攻撃パターンでは、攻撃者は、不正なアップリンク局を使って、標的となる衛星に妨害的な信号を送り、意図された送信を妨害する。その衛星のフットプリント（電波の届く範囲）内にいる者は、標的、あるいは隣接するチャンネルに到達することを妨げられる。衛星のフットプリントの大きさは、その衛星が空のどの位置にあるかによって決まる。より高い軌道上の衛星は、複数の大陸を覆うことがある。
prerequisites/0/0: この攻撃には、標的を定めるための、衛星の座標についての知識が必要である。
resources/0/0: 衛星アップリンク局。
consequences/0/note/0: この攻撃が成功すると、認可された利用者による衛星通信の可用性が失われる。
s.summary: 衛星通信そのものを狙い、不正なアップリンク局から妨害電波を送り込むことで、その衛星の電波が届く範囲（フットプリント）にいる正当な利用者全員の通信を妨害してしまう攻撃。高い軌道の衛星ほどフットプリントが広く、複数の大陸にまたがる被害範囲になり得る。
s.term: フットプリント, footprint, 衛星からの電波が届く、地上の範囲のこと。衛星の軌道の高さによって、その広さが変わる。
s.fact: この攻撃が成功すると、認可された利用者による衛星通信の可用性が失われる、と原典のconsequences（起こり得る結果）に書かれている。, CAPEC-559 consequences
s.analogy: ラジオ放送局の周波数に、別の強い電波を送り込んで、そのラジオの放送エリア全体でまともに受信できなくしてしまうのに似ている。
